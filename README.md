# 🧩 Compton-Paper – Der Compton-Effekt

Dieses Repository enthält das vollständige LaTeX-Projekt  
**„Der Compton-Effekt – Herleitung im historischen und theoretischen Kontext“**  
von **Christian Weilharter**  
(*Math & Physics Open Science Collection*).

---

## 📂 Projektstruktur
```
Compton-Effekt/
│
├── bib/
│ └── literatur.bib # Gemeinsame Literaturdatenbank (BibLaTeX)
│
├── de/ # Deutsche Version
│ ├── compton_de.tex # Hauptdatei (Deutsch)
│ ├── figures/ # Abbildungen (deutsche Labels)
│
├── en/ # Englische Übersetzung
│ ├── compton_en.tex # Main file (English)
│ ├── figures/ # Figures (English captions)
│
├── styles/
│ ├── paper-style-de.sty # Stilvorlage für deutsche Version
│ └── paper-style-en.sty # Style file for English version
│
└── README.md
```
